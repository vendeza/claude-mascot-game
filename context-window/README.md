# Context Window

Фанатский пошаговый рогалик в браузере. Clawd спускается по этажам-репозиториям, а вместо здоровья у него контекстное окно на 200k токенов.

- Урон, вызовы инструментов и предметы заполняют контекст.
- `/compact` сжимает шум и вывод, но может превратить предметы в саммари. Перезарядка 15 ходов.
- Если контекст переполнился, пока компакция перезаряжается, сессия окончена.

Один файл `index.html` без зависимостей. Чтобы поиграть, открой его в браузере.

Фанатский проект, не связан с Anthropic.
